# Open Library Prototype

A minimal web app built with Lit web components and Vite, inspired by Open Library.

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm

### Installation

1. Clone the repository:
```bash
git clone https://github.com/lokesh/open-library-prototype.git
cd open-library-prototype
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser to the URL shown in the terminal (typically `http://localhost:5173`)

## What's in it

- **Views & Verbs prototype** — home, search, author, subject, My Books, reading log, list and book pages built on one `ol-book-collection` component (grid / list / carousel), a shared `ol-book-actions` row (Access verb + Save ▾ menu), a peek panel, and a ⚙ drawer to switch design variants. See `public/docs/views-and-verbs.html` for the exploration and `public/docs/views-and-verbs-playground.html` for the standalone playground.
- Earlier explorations: import wizard, book editing, series management, component showcase.

Data is mock: `public/data/catalog.json` (generated by `scripts/build-catalog.py`). Reader state (shelves, lists, ratings, signed-in) lives in localStorage — use **Reset my books** in ⚙ to restore defaults.
